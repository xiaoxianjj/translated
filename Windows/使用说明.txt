Translated 1.2.9 · Windows 10 / 11

启动 Translated.exe。关闭主窗口后，程序会留在通知区域。双击托盘图标可打开主窗口，右键菜单的 Quit / 退出可结束程序。

划选翻译

拖选、双击单词、Shift 扩选或 Ctrl+A 后，支持的文本控件会在选区旁显示 Translate。点击浮钮或按 Ctrl + Shift + F8 开始翻译。两种入口均将英文译为所选的简体或繁体中文，将其他语言译为英文。快捷键可在 Settings 修改。

可编辑区域在重新核对原应用、控件、范围和文本后替换所选部分。只读或无法确认可编辑的区域会复制完整译文。关闭原位替换后，或选区、焦点、剪贴板发生变化时，译文会保留供手动查看。翻译期间点击、滚动、打字、切换应用或更新剪贴板都会影响自动交付。右键通知区域图标选择 Translation result 可查看保留的译文或错误、复制译文或重试。Esc 取消当前任务，新请求取代旧请求。

用快捷键或选区浮钮翻译时，底部状态条会显示交付结果。Replaced 表示已确认替换，可以重新框选译文再翻译。Copied 表示译文已复制到剪贴板。Review result 表示译文需要手动核对，可在托盘菜单中选择 Translation result 查看。

编辑器暂时未能提供选区时，程序会使用同一份译文自动再次核对。最近一次核对失败的时间、版本、步骤、原因与耗时保存在 LocalAppData/Translated/last-selection-check.txt。该文件仅含诊断信息，每次覆盖。

主窗口与设置

Translate 页支持粘贴、输入和 Ctrl + Enter，译文直接显示在当前页面。上限为 50,000 个文本元素。长文分块完成后才提供结果。纯数字、标点或 emoji 不能单独发起翻译。

Settings 中选择 DeepSeek、OpenAI 或 Custom / Local LLM，填写模型、地址和所需的 API key，然后点击 Save settings。Test translation 会用当前填写的参数发送一个示例，可能计费。测试不改变已保存的服务。远程地址使用 HTTPS，本机回环地址也可使用 HTTP。Apple 本地翻译只适用于 macOS。

密钥保存在 Windows 凭据管理器中，按服务商和完整接口地址隔离。新地址需使用自己的密钥。常规偏好位于本机 LocalAppData 下的 Translated/settings.json，程序不写入翻译历史。一次请求失败后由使用者决定是否重试。

兼容取词与剪贴板

优先使用 Windows UI Automation 或原生编辑框的选区。需要借用剪贴板时，程序会先保存可还原的格式，并按所有者与版本号恢复。新复制的内容优先。无法安全保存原格式时，使用主窗口粘贴或手动复制。剪贴板管理器有可能记录临时复制。已中断且无法归属的异步复制可能留在剪贴板中。

Check WeChat selections with Copy 允许在微信暴露了安全文本控件、但没有直接返回文字时，通过临时复制核实选区。无法取得可靠范围时只允许复制译文。微信聊天区、图片文字和应用自绘控件的支持取决于应用实际提供的接口。
