Translated 1.2.9 · Windows 10 / 11

启动 Translated.exe。关闭主窗口后，程序会留在通知区域。双击托盘图标可打开主窗口，右键菜单的 Quit / 退出可结束程序。

划选翻译

拖选、双击单词、Shift 扩选或 Ctrl+A 后，支持的文本控件会在选区旁显示 Translate。点击浮钮或按自定义快捷键（默认 Ctrl + Shift + F8）开始翻译，选区旁会弹出译文卡片，显示加载状态和完整译文。卡片首次出现不抢走原输入框焦点；译文可选取，长文可滚动查看，点击“复制译文”才会主动复制结果。

卡片的“翻译为”可选择简体中文、繁體中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、阿拉伯语、印地语、意大利语、泰语、越南语、印度尼西亚语、土耳其语、荷兰语、波兰语、乌克兰语、马来语。程序自动识别原文语言；明确选择的目标语言优先。选择“自动 · 英语 ↔ 中文”时保留英文译为所选简繁中文、其他语言译为英文的规则。

切换语言会用本次已捕获的原文重新翻译，无需重新划词；选择会保存并同步到主界面。新请求取代旧请求。卡片提供失败信息和“重新翻译”。关闭按钮、Esc 或 Alt+F4 都会关闭卡片并取消请求；语言列表展开时 Esc 先收起列表。卡片显示时临时置前，避免被原应用挡住；点击或滚动卡片外部、在原应用继续输入或切换到其他应用时自动收起，撤销置前并取消未完成请求。卡片内的语言下拉列表和复制操作仍可正常使用。已完成的最近结果可在托盘菜单 Translation result 中取回。切换语言及重试会调用当前保存的翻译服务，按该服务规则计费。

默认卡片模式不替换原文，也不自动覆盖剪贴板。在 Settings 关闭“划词后弹出译文卡片”，可恢复下列自动交付方式。

可编辑区域在重新核对原应用、控件、范围和文本后替换所选部分。只读或无法确认可编辑的区域会复制完整译文。关闭原位替换后，或选区、焦点、剪贴板发生变化时，译文会保留供手动查看。翻译期间点击、滚动、打字、切换应用或更新剪贴板都会影响自动交付。右键通知区域图标选择 Translation result 可查看保留的译文或错误、复制译文或重试。Esc 取消当前任务，新请求取代旧请求。

使用自动交付方式时，底部状态条会显示交付结果。Replaced 表示已确认替换，可以重新框选译文再翻译。Copied 表示译文已复制到剪贴板。Review result 表示译文需要手动核对，可在托盘菜单中选择 Translation result 查看。

编辑器暂时未能提供选区时，程序会使用同一份译文自动再次核对。最近一次核对失败的时间、版本、步骤、原因与耗时保存在 LocalAppData/Translated/last-selection-check.txt。该文件仅含诊断信息，每次覆盖。

主窗口与设置

自定义快捷键（Windows）

在 Settings 的 Translation shortcut 区域点击“自定义快捷键…”。弹窗显示系统识别到的键盘和鼠标名称，并使用通用拟物布局。直接按实体组合，或点击键帽、鼠标中键、M4/M5 侧键选择；绿色代表已选中，实体按住时键帽下沉。实体组合松开后保留预览，再次录制新组合会替换预览，也可用“清空重录”。点击已选键帽可取消该键；点击虚拟修饰键后也可按实体键继续组合。

窗口会根据当前显示器的工作区和缩放适配尺寸；内容区可滚动，保存和取消按钮固定在底部。

点击“保存快捷键”后生效；取消、Esc 或关闭弹窗保留原设置。普通键盘组合会检查系统注册冲突；鼠标与多键组合不能全面检测其他软件的绑定，请选择不冲突的组合。最多支持四个普通按键另加修饰键，普通字母需搭配 Ctrl、Alt 或 Win；鼠标侧键、中键可单独使用。不支持独立 Fn、Esc、F12、滚轮滚动和驱动未暴露的专用宏键。Fn/宏键可先在设备驱动中映射为普通按键。

录制仅在弹窗激活时进行，切换应用会暂停；“继续录制”可恢复。保存后关闭应用并重启仍会保留。鼠标组合触发时会拦截完成组合的按键，避免侧键同时执行前进/后退；组合未按全时保留原有行为。建议先按修饰键，再按普通键或侧键。该功能当前仅在 Windows 版本提供。

Translate 页支持粘贴、输入和 Ctrl + Enter，译文直接显示在当前页面。上限为 50,000 个文本元素。长文分块完成后才提供结果。纯数字、标点或 emoji 不能单独发起翻译。

Settings 中选择 DeepSeek、OpenAI 或 Custom / Local LLM，填写模型、地址和所需的 API key，然后点击 Save settings。Test translation 会用当前填写的参数发送一个示例，可能计费。测试不改变已保存的服务。远程地址使用 HTTPS，本机回环地址也可使用 HTTP。Apple 本地翻译只适用于 macOS。

每个任务使用发起时的翻译服务、模型、目标语言和简繁体偏好。修改设置只影响后续新任务，已排队任务保持原有服务配置。

密钥保存在 Windows 凭据管理器中，按服务商和完整接口地址隔离。新地址需使用自己的密钥。常规偏好位于本机 LocalAppData 下的 Translated/settings.json，程序不写入翻译历史。一次请求失败后由使用者决定是否重试。

兼容取词与剪贴板

优先使用 Windows UI Automation 或原生编辑框的选区。对云登等 Chromium 衍生浏览器，在卡片模式下明确按快捷键、但没有可用的文字范围时，会检查原浏览器内容区焦点与非密码状态，再使用 Ctrl+C 兼容取词；该途径仅预览，不授权自动替换。没有有效选区或无法确认来源时不会发起翻译。需要借用剪贴板时，程序会先保存可还原的格式，并按所有者与版本号恢复。新复制的内容优先。无法安全保存原格式时，使用主窗口粘贴或手动复制。剪贴板管理器有可能记录临时复制。已中断且无法归属的异步复制可能留在剪贴板中。

Check WeChat selections with Copy 允许在微信暴露了安全文本控件、但没有直接返回文字时，通过临时复制核实选区。无法取得可靠范围时只允许复制译文。微信聊天区、图片文字和应用自绘控件的支持取决于应用实际提供的接口。
