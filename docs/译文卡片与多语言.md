# Windows 译文卡片与多语言

## 使用方式

1. 划选文字，按已保存的翻译快捷键，或点击选区旁的 Translate。
2. 卡片在选区附近显示加载状态，完成后直接展示可选取、可滚动的译文。首次显示不抢占原输入框焦点。
3. 在“翻译为”选择目标语言，程序使用本次捕获的原文重新翻译。语言选择会保存，并同步到主界面。
4. 点击“复制译文”复制结果；失败后可点击“重新翻译”。关闭按钮或 Esc 关闭卡片并取消当前请求，展开语言列表时 Esc 先收起列表。卡片仅在预览期间临时置前，以便在不抢焦点的情况下显示于原应用上方；点击／滚动卡片外部、在原应用继续键盘操作或切换到其他应用时自动收起、撤销置前并取消未完成请求。语言下拉框作为卡片的一部分保留交互。

默认使用卡片模式，保留原文，不自动写入译文到剪贴板。在 Settings 关闭“划词后弹出译文卡片”，可恢复原来的自动替换／复制方式。卡片关闭后，最近一次结果仍可在托盘的 Translation result 中查看；程序不保存翻译历史到磁盘。

## 目标语言

支持 21 种明确目标：简体中文、繁體中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语、阿拉伯语、印地语、意大利语、泰语、越南语、印度尼西亚语、土耳其语、荷兰语、波兰语、乌克兰语、马来语。

原文自动识别，明确目标始终优先于原文语言提示。阿拉伯语译文使用从右向左的显示方式。另提供“自动 · 英语 ↔ 中文”：英文翻译为设置中的简体或繁体中文，其他语言翻译为英文。

继续使用现有 DeepSeek、OpenAI 或兼容 Chat Completions 的自定义服务，无需新增账户。翻译能力取决于所选模型。每次切换语言或重试都会调用所选服务，适用该服务的计费规则。

## 实现位置

- `Windows/Core/TranslationLanguages.cs`：稳定语言代码、显示名称、提示词目标和文字方向。
- `Windows/Core/Translator.cs`：明确目标路由，保持分块、格式和保护片段逻辑。
- `Windows/TranslationCard.xaml`、`Windows/TranslationCard.cs`：卡片的加载、成功、错误、语言选择和复制交互。
- `Windows/Program.cs`：共用原有选区捕获流程；捕获后按显示方式分流。每个任务固定原文与目标，新任务取消旧任务，关闭后不接收迟到结果。
- `Windows/Workspace.xaml`、`Windows/Workspace.cs`：主界面目标语言和卡片模式开关。
- `Windows/Core/Configuration.cs`：新增 `SelectionMode` 和 `TargetLanguage`，旧配置缺失时默认卡片与自动中英互译，保留原快捷键、服务及其他设置。

取词优先使用原生控件或应用提供的 UI Automation 接口。云登等 Chromium 衍生浏览器缺少可用文字范围时，明确按快捷键可使用复制取词：核对原窗口、Chrome 内容区 HWND、UIA 非密码状态及焦点后，仅复制当前选区用于卡片预览。不会发送 Ctrl+A，也不会借此替换原文。剪贴板继续使用原来的完整保存、所有者与版本核对、恢复机制；无法安全保留格式时提示手动粘贴，不覆盖已有内容。

读取过程中切换窗口或出现新的输入会取消捕获，不再把过期的错误卡片弹到其他应用上。初始捕获失败的诊断写入已有的 `last-selection-check.txt`，不记录原文或窗口标题。

快捷键触发前先同步实际前台窗口，忽略空窗口和已过期的异步窗口通知；卡片预览在快捷键松开、浏览器焦点稳定后读取当前选区。读取时有进度提示；同一窗口内无法确认选区时显示原因，不再无提示消失。自动收起仅作用于已显示的卡片，过滤短暂的窗口切换；卡片可见时额外定时检查前台窗口及原窗口是否最小化，避免仅依赖 WinEvent 通知。`last-shortcut-state.txt` 覆盖保存最近一次快捷键阶段和注册状态；`last-shortcut-trace.txt` 在本次进程内最多保留 48 个阶段与取消原因。均不含原文、输入内容或窗口标题。

## 验证

构建：`dotnet build Windows/Tests/Translated.Tests.csproj -c Release -f net48 -o BuildLogs/translation-card/tests`。

- 运行 `BuildLogs/translation-card/tests/Translated.Tests.exe`：核心测试，覆盖 21 种目标、原文提示优先级、旧配置迁移、分块、请求取消和现有快捷键行为。
- 加 `--cards`：独立进程中的真实原生文本选区、本机模拟 HTTP 翻译服务、卡片加载与译文、目标切换、保存语言、阿拉伯语方向、并发切换、失败重试、关闭取消、原文与剪贴板保持，以及旧自动替换方式。
- 加 `--cards-real-hotkey`：向独立原生测试窗口发送真实组合键，验证系统快捷键、Raw Input、取词、卡片流程及迟到的前台通知回归。测试窗口必须激活；不会向其他窗口发送按键。
- 加 `--render BuildLogs/translation-card/renders`：明暗主题、加载／成功／错误、最小窗口和多显示器边缘定位。
- 加 `--card-preview`：仅使用临时设置和本机模拟服务的可交互卡片，用于鼠标与键盘验收。Esc 关闭后退出测试。
- 加 `--browser-card-compat <chrome.exe 路径>`：独立浏览器配置和本地网页，直接从无 TextPattern 范围的复制候选进入共享流程，验证兼容复制、原剪贴板恢复、卡片临时置前与切换窗口后撤销。测试仅操作临时网页，不使用个人浏览器配置。

这些验证不调用真实付费翻译服务。真实翻译质量和各软件的取词兼容性需要结合使用者所选模型与应用实际验证。
